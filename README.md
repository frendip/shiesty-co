# Shiesty Company

Сайт бренда одежды Shiesty Company с каталогом, страницами товаров, фотографиями и интерактивным 3D-просмотром футболки. Покупатель выбирает размер и заполняет форму, после чего открывается Telegram с подготовленным сообщением менеджеру. Оплата и завершение заказа происходят вне сайта.

**Стек:** Next.js 15, React 19, TypeScript, Tailwind CSS 4, Three.js / React Three Fiber, React Hook Form, Swiper.

## Требования

- Node.js 22.x, npm 10.x и Git.
- Современный браузер с поддержкой WebGL для 3D-просмотра.
- Свободный порт 3000. Отдельная база данных, API-сервис и ключи не нужны.

## Локальный запуск

```bash
git clone https://github.com/frendip/shiesty-co.git
cd shiesty-co
npm ci
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Для другого порта используйте, например, `npm run dev -- --port 3001`.

Каталог хранится в `src/data/products.json`. Серверные страницы читают его напрямую через общие функции; этот же каталог доступен по HTTP через `/api/products` и `/api/products/[id]`. Настраивать `NEXT_PUBLIC_API_URL` или запускать второй экземпляр сайта не требуется.

Форма заказа открывает ссылку на менеджера бренда. Для использования проекта с другим магазином измените получателя в `src/components/Purchase.tsx`.

## Сборка и production-запуск

```bash
npm run build
npm start
```

Сборка выполняется без запущенного сервера и внешнего API каталога. После изменения `src/data/products.json` пересоберите и перезапустите приложение, чтобы обновить данные в production.

В проекте также есть Dockerfile для standalone-сборки.

## Проверка

```bash
npm test
```

Проверка собирает приложение без доступного внешнего API, запускает production-сервер на свободном локальном порту и проверяет каталог, фильтры, карточку товара и ответы 404. После завершения тестовый сервер останавливается. Не запускайте тест одновременно с dev-сервером или другой сборкой в той же папке: они используют общий каталог `.next/`.

Установка, production-сборка и проверка каталога выполнены на Node.js 22.22.3 и npm 10.9.8.
